# Contributing

This repo is the canonical PiB skill pack.

1. Edit skills here (or in the `partnersinbiz-web/packs/pib-system-skills` submodule).
2. Keep `skills/<name>/SKILL.md` Agent Skills-compliant (`name` matches the folder).
3. Interactive API work uses device OAuth / personal tokens. Do not document `AI_API_KEY` as the default.
4. Push to `main`. The web app vendors this tree as a submodule on `development`.
